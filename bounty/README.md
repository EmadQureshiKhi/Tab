# Bounty demo videos

One short video per Monad Metropolis bounty Tab is entered for, each narrated and captioned.
Click a file to watch it here on GitHub.
Everything shown was recorded against the live deployment: [trytabai.vercel.app](https://trytabai.vercel.app) and its hosted services on Monad Mainnet and Testnet.

| Bounty | Video | What it shows |
| --- | --- | --- |
| Chainlink, Best workflow with CRE | [chainlink-cre.mp4](chainlink-cre.mp4) | A real `cre workflow simulate` run of the delinquency keeper workflow: cron trigger, overdue tabs read under consensus, the secret, and the mark landing on Monad Testnet |
| Nansen, Best use of Nansen | [nansen.mp4](nansen.mp4) | The Nansen profile the registry buys over x402 for each Agent, its three Mainnet payments, and Nansen fronted on credit under `/hub/nansen` |
| Envio, Best Use of Envio | [envio.mp4](envio.mp4) | A timed cold catch-up of the registry: HyperSync against plain RPC, and the pages that index drives |
| Privy | [privy.mp4](privy.mp4) | An Agent whose key is a Privy server wallet: Privy's own policy refusal, then the whole loop signed by Privy and settled |
| Aurora Intents, Bring Any-Chain Liquidity to Monad | [aurora-intents.mp4](aurora-intents.mp4) | The intents-funded Settlement that ran on Mainnet: USDC deposited on Arbitrum, delivered to Monad, and the tab settled |
| Monad Foundation, Best Mera-Powered UX on Monad | [mera-ux.mp4](mera-ux.mp4) | Mera as the whole account: a passkey account, its owner and session keys, an authorisation signed in the page, and the keys back after a reload |
| Monad Foundation, Mera: One Passkey, Many Keys | [mera-one-passkey.mp4](mera-one-passkey.mp4) | The agent book on `/keys`: the same passkey seals the owner's notes on each Agent under a PRF namespace of its own, which signs nothing |

The full product walkthrough is the [demo video](https://youtu.be/k8_eo5tZoFI).
